# Paradise Nursery Shopping Application

Paradise Nursery is an online e-commerce platform designed for plant lovers to browse, discover, and purchase a wide variety of houseplants.

## Features
- **Landing Page:** Interactive homepage with background styling and a "Get Started" button.
- **Product Listing:** Browse plants categorized into Air Purifying, Aromatic, and Medicinal categories with working "Add to Cart" state management.
- **Redux Shopping Cart:** Dynamic cart functionality allowing users to adjust quantities, view total amounts, and calculate individual sub-totals.
- **Navigation:** Header navbar showing dynamic total item counts.
